🚨 TROUBLESHOOTING:

❌ "I don't see the buttons"
✅ Make sure you're looking at the right section: "Phân bổ theo Người thu (Chi tiết)"
✅ Check if JavaScript is enabled in your browser
✅ Try refreshing the page (Ctrl+F5)

❌ "The buttons don't work"
✅ Open browser console (F12) and check for JavaScript errors
✅ Try running: setCollectorDateType('custom') in the console

❌ "The green box doesn't appear"
✅ Clear browser cache and reload
✅ Check if the Flask app is running without errors
